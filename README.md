# 여호수아와 여리고 성 · 그림 이야기

한 장의 그림이 펜을 따라 완성되는 Three.js 웹 이야기입니다.

- 기본 화면: V3 — 사군자 먹붓과 화선지, 두 사람의 대화와 마지막 캐릭터 모션.
- V3: 수묵 밑그림 위의 사군자 먹붓과 화선지, 목탄, 검정 크레용, 수묵 담채화.
- 상단 버전 메뉴: V1 / V2 / V3 비교.
- 모바일: 큰 재생 버튼, 접을 수 있는 그리기 설정, 가로 전체 화면 감상.
- 전체 보기에서는 그림만 표시하며, 하단 터치 시 재생·탐색·돌아가기 버튼이 나타납니다.
- 효과음 없이 목소리와 음악만 재생됩니다.

Three.js 라이선스는 각 버전의 `vendor/LICENSE`에 포함되어 있습니다.
이 저장소에는 정적 웹페이지와 재생에 필요한 이미지·음원만 들어 있습니다.
